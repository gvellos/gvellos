#### 🛠️ Selected work

🛰️ **[Blue Shadow](https://github.com/gvellos/Blue-Shadow)** · Python · Remote sensing
Detects ships in Sentinel-1/2 and ICEYE satellite imagery, cross-references them against Danish Maritime Authority AIS data at capture time, and produces a ranked queue of "dark" vessels for analysts, each with an explainable reason code.
`CFAR detection` · `SAR & optical imagery` · `AIS interpolation` · `geospatial pipelines`

📈 **[Startup Finance Copilot](https://github.com/gvellos/Startup-Finance-Copilot)** · Python · LLM agents
Multi-agent LLM platform that generates financial forecasts, analyses risk, surfaces funding opportunities and drafts investor-ready pitch decks.
`multi-agent orchestration` · `LLMs` · `financial modelling`

🧾 **[Invoice Copilot](https://github.com/gvellos/Invoice-Copilot)** · Python · Document AI
AI assistant for extracting, validating and organising invoice data.
`document understanding` · `LLMs` · `automation`

🎙️ **[Speech vs. Background Segmentation](https://github.com/gvellos/Speech-vs-Background-Segmentation-System)** · Python · Audio ML
Frame-level classifier that separates speech from background audio. Includes feature extraction, Least Squares and MLP models, and evaluation against ground-truth annotations.
`signal processing` · `MLP` · `evaluation`

🏠 **[Perceptron for House Price Prediction](https://github.com/gvellos/Perceptron-for-House-Price-Prediction)** · Python · Classical ML
Perceptron, linear regression and a neural network implemented and compared on the California Housing dataset, with a full preprocessing and evaluation pipeline.
`from-scratch ML` · `regression` · `data analysis`
